# 消火設備点検チェックリスト

点検・作業の手順をチェックリストとして登録し、現場でタップしながら一つずつ消し込んで完了させる、オフライン対応のPWA（Progressive Web App）です。
消火器・消火栓・スプリンクラーなど、消火設備の点検業務向けの個人用チェックリストツールとして作られています。

**公開URL：** https://maru-aicode.github.io/shobo-setsubi-checklist/

## 主な機能

- **ホーム** — 最近実施したチェックリストを新しい順に表示、登録済みチェックリスト一覧を表示
- **登録** — チェックリスト（名前・説明・項目）を自分で追加・編集・削除
- **実行** — チェックリスト項目をタップして一つずつ消し込み、全項目完了で完了スタンプを表示
- **検索** — チェックリスト名・説明・項目本文を横断検索
- **バックアップ** — データをJSONファイルとして書き出し／読み込み

## オフライン対応について

- データはすべて端末内のlocalStorageに保存され、サーバーには送信されません
- Service Workerがページ本体をキャッシュするため、一度開けば機内モードでも動作します
- iPhoneでは、Safariでこのページを開いた後、共有ボタン→「ホーム画面に追加」でアプリのように利用できます
- Androidでは、Chromeでこのページを開いた後、メニュー→「アプリをインストール」でホーム画面に追加できます

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）
- `manifest.json` / `service-worker.js` によるPWA対応
- GitHub Pagesで静的ホスティング

## ファイル構成

```
index.html      アプリ本体（UI・ロジック）
manifest.json   PWAマニフェスト
service-worker.js  Service Worker（オフラインキャッシュ）
icons/          ホーム画面用アイコン
```

## 注意事項

- データはブラウザ・端末ごとのlocalStorageに保存されるため、複数端末間では自動同期されません。端末間で持ち運ぶ場合は「データ管理」機能のエクスポート／インポートをご利用ください
- サンプルデータとして、消火器点検の代表的なチェック項目（製造年月日・ホースの詰まり・圧力針・安全栓・底の錆など）を初期登録できます（ホーム画面の案内から追加）
