# 消火設備点検チェックリスト PWA

## ファイル構成
- `index.html` … アプリ本体
- `manifest.json` … アプリ名・アイコン・起動設定
- `service-worker.js` … オフラインキャッシュ
- `icons/` … アプリアイコン（192px / 512px / maskable）

## 使い方（インストール手順）

このzipを展開したフォルダをそのまま **HTTPSで配信できるホスティングサービス** に置いてください。
PWAはセキュリティ上の理由で `https://` （または `localhost`）配信でないとインストールできません。

おすすめの方法（すべて無料）：

1. **Netlify Drop**: https://app.netlify.com/drop にフォルダごとドラッグ＆ドロップするだけで公開できます。
2. **GitHub Pages**: リポジトリにこのフォルダをpushし、Settings → Pages で公開。
3. **Vercel**: `vercel` コマンドでフォルダをそのままデプロイ。

公開後、スマホでそのURLを開き、
- iPhone(Safari): 共有ボタン →「ホーム画面に追加」
- Android(Chrome): メニュー →「アプリをインストール」

でホーム画面にアイコンが追加され、オフラインでも起動できるようになります。

## データについて
データは端末のブラウザ内（localStorage）に保存されます。他のサーバーには送信されません。
機種変更やブラウザの再インストール時は、アプリ内の「データ管理」からエクスポートしたJSONファイルを、新しい端末でインポートしてください。

## ローカルでの動作確認
Service Workerは `file://` では動作しないため、簡易サーバーを立てて確認してください。

```bash
cd このフォルダ
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いて確認できます。
